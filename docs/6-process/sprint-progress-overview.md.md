## Initial Goals & Objectives

The initial project goals focused on establishing a scalable and accessible foundation for the Venture Pipeline Management System (VPMS).

### Initial Objectives

- Establish a structured venture pipeline management workflow
- Centralise venture submissions and documentation
- Improve visibility into venture progress and reviews
- Introduce role-based access control
- Improve operational consistency across stakeholders
- Support accessibility and usability considerations
- Develop a scalable MVP foundation for future expansion

### Initial Technical Priorities

- Core frontend structure
- Authentication and access control
- Submission and review workflows
- Documentation organisation
- Frontend/backend integration planning
- Accessibility-first UI considerations
