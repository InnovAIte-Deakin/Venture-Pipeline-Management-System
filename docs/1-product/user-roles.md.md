# User Roles & Permissions

---

# 1. Overview

VPMS uses role-based access control (RBAC) to ensure users only access features relevant to their responsibilities.

The platform supports:
- A full web experience for advanced workflows and administration
- A simplified mobile experience focused on accessibility and usability

---

# 2. User Roles

## Impact Users

Impact users use VPMS to submit and manage venture applications.

### Capabilities
- Submit venture applications
- Upload documents
- Edit venture information
- Track application status
- Respond to requested changes

### Platform Access
- Web platform
- Mobile platform

### Experience Focus
- Simple navigation
- Accessibility-first interactions
- Reduced complexity

---

## Admins / Analysts

Admins and analysts manage the review and workflow process.

### Capabilities
- Review applications
- Approve, reject, or request changes
- Manage workflow stages
- Monitor venture progress
- Access administrative features

### Platform Access
- Web platform

### Experience Focus
- Workflow management
- Administrative controls
- Data and review processes

---

# 3. Permissions Overview

| Feature | Impact Users | Admins / Analysts |
|---|---|---|
| Submit Applications | Yes | No |
| Upload Documents | Yes | Yes |
| Edit Venture Information | Own Only | Yes |
| View Venture Status | Yes | Yes |
| Review Applications | No | Yes |
| Approve / Reject Applications | No | Yes |
| Manage Workflow Stages | No | Yes |
| Access Admin Features | No | Yes |
| Access Web Platform | Yes | Yes |
| Access Mobile Platform | Yes | Limited |

---

# 4. Accessibility Considerations

VPMS supports users with different levels of digital literacy through:
- Simplified mobile interactions
- Clear navigation
- Reduced cognitive load
- Accessibility-focused design

---

# 5. Key Principle

Each user role is provided with access and interface complexity appropriate to their responsibilities and workflow needs.
