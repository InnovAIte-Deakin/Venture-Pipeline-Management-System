# Web Version User Guide for Founders & Admins

---

# 1. Introduction

The web version of the Venture Pipeline Management System (VPMS) is designed specifically for Founders and Administrators to efficiently manage ventures, monitor business performance, and oversee overall system operations.

This guide provides step-by-step instructions on how to use the major features available within the VPMS web platform.

---

# 2. System Access

## Login Process

To access the system:

1. Open the VPMS web application in a supported web browser
2. Enter your registered email address and password
3. Click the **Login** button

After successful authentication, users will be redirected to the Dashboard page.

## Notes

- Ensure your login credentials are entered correctly
- Contact the system administrator if login issues persist

---

# 3. Dashboard

## Purpose

The Dashboard serves as the central overview page of the VPMS platform.

It allows Founders and Administrators to quickly monitor venture activity, performance indicators, and recent updates.

---

## Key Components

### Summary Cards
Displays important system statistics such as:

- Total ventures
- Active projects
- Pending activities
- User engagement metrics

### Performance Indicators
Provides insights into:

- Venture growth trends
- Impact metrics
- Overall performance

### Recent Activity Feed
Displays the latest system activities and updates.

### Notifications Preview
Shows important alerts and announcements.

---

## How to Use

1. Navigate to the **Dashboard** from the sidebar menu
2. Review the summary cards at the top of the page
3. Monitor key performance indicators
4. Scroll down to view recent activities and notifications
5. Use the dashboard information to track overall system status
