## 4. Main Features

---

## 4.1 Dashboard (Home)


![dashboard](https://hackmd.io/_uploads/rJF8t25JGg.png)
*Figure 4: Dashboard showing overview, quick access features, and venture status*

The Dashboard is the main entry point of the application and provides a quick overview of venture activity, progress, and key actions.

---

### 4.1.1 Overview Section

At the top of the dashboard, users can view:

- Total active ventures (e.g., “2 Active Ventures”)  
- A short summary of actions such as viewing ventures, uploading documents, and tracking progress  
- A quick **“+ Add”** button to start a new venture  

---

### 4.1.2 Quick Access

The Quick Access section provides shortcuts to key features:

- **Ventures** – View venture details  
- **Documents** – Upload and check document status  
- **Meetings** – View upcoming meetings  
- **Analytics** – Track venture progress  

These shortcuts improve navigation efficiency and reduce the need to switch tabs.

---

### 4.1.3 Venture Status

Displays the current progress of ventures.

Includes:
- Progress bar (e.g., “In Progress”)  
- Current stage (e.g., Document Review)  

This helps users understand where their venture stands in the process.

---

### 4.1.4 Documents Summary

Provides a quick overview of document status:

- Uploaded documents  
- Pending documents  
- Approved documents  

Users can also tap **“View all”** to see complete details.

---

### 4.1.5 Recent Updates

Shows the latest updates related to ventures, documents, or activities.

This ensures users stay informed about recent changes.

---

### 4.1.6 Language Switch

Users can switch between available languages (e.g., English and Khmer) using the toggle at the top of the screen.

---

### 4.1.7 Key Functionality

The Dashboard allows users to:
- Quickly access important features  
- Monitor venture progress  
- Track document status  
- Stay updated with recent activities

## 8. System Workflow Overview

The application follows this workflow:

1. User registers and logs in  
2. User submits a venture  
3. Documents are uploaded and reviewed  
4. Progress is tracked via dashboards  
5. Notifications provide updates  
6. Reports support decision-making
