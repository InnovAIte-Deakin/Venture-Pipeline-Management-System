# Goals & Objectives

---

# 1. Trimester Goals

This trimester focuses on evolving VPMS from a Minimum Viable Product (MVP) into a more accessible, scalable, testable, and deployment-ready prototype.

The primary focus is improving usability, strengthening platform readiness, and refining the overall experience across both web and mobile platforms.

## Key Priorities

- Prepare the platform for external hosting and deployment
- Simplify authentication workflows and explore Single Sign-On (SSO) integration
- Improve usability for users with varying levels of digital literacy
- Refine venture submission and review workflows
- Enhance accessibility, readability, and interface consistency
- Improve testing, validation, and deployment readiness

---

# 2. Mobile Accessibility Objectives

To better support impact users, VPMS introduces a mobile-focused experience designed around accessibility and simplicity.

## Objectives

- Design a simplified and intuitive mobile interface
- Reduce cognitive load and interaction complexity
- Improve usability for users with low digital literacy
- Provide clear visibility into venture status and updates
- Ensure consistency between mobile and web platform data
- Improve navigation clarity and readability on smaller devices

---

# 3. Trimester Deliverables

The following deliverables are targeted during this trimester.

## Core Deliverables

- Externally accessible prototype or deployment-ready environment
- Improved authentication and account management experience
- Functional sandbox/testing environment for stakeholder evaluation
- Streamlined venture submission and review workflows
- Accessibility-focused UI and UX enhancements
- Mobile interface prototypes and responsive layouts

## Technical Deliverables

- Role-based data handling and permissions
- Improved validation systems
- Frontend and backend integration refinements
- Environment configuration standardisation
- Increased testing and validation coverage
- Improved documentation and development workflows
