# Dashboard
## Venture Pipeline Management System (VPMS)

---

# Overview

The Dashboard is the main entry point of VPMS. It provides users with an overview of venture applications, workflow progress, and important updates related to their role.

---

# Purpose

The dashboard is designed to:
- Provide a summary of venture applications
- Display workflow and submission statuses
- Highlight important updates
- Support easier navigation across the platform

---

# Sprint 2 Progress

Sprint 2 improvements included:
- Improved navigation structure
- Better workflow visibility
- Enhanced status tracking
- Responsive layout improvements
- Improved accessibility and readability

---

# Web Experience

## Impact Users
Impact Users can:
- View application progress
- Track submission statuses
- Access uploaded documents
- View notifications and updates

## Administrators
Administrators can:
- View all venture applications
- Monitor workflow pipeline status
- Review submissions requiring action
- Track application activity

---
