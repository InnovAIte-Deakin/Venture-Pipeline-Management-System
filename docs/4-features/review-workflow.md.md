# Review Workflow
## Venture Pipeline Management System (VPMS)

---

# Overview

The Review Workflow allows administrators to review venture submissions and manage application statuses throughout the evaluation process.

The workflow provides a structured and consistent process for tracking submission progress and review outcomes.

---

# Purpose

The Review Workflow is designed to:
- Support consistent application reviews
- Track submission progress and statuses
- Improve workflow visibility
- Provide clear status updates to users

---

# Sprint 2 Progress

Sprint 2 improvements included:
- Improved workflow visibility
- Enhanced status tracking
- Better review navigation and layout
- Improved responsiveness across devices
- Clearer workflow status indicators
- Improved accessibility and readability

---

# Workflow Stages

Submissions move through the following stages:

- **Pending** — Submission is awaiting review
- **Approved** — Submission meets requirements
- **Rejected** — Submission does not meet requirements
- **Needs Changes** — Additional updates or information are required

---

# Web Experience

The web platform provides administrators with a more detailed review and management experience, including workflow monitoring, status management, and submission review actions.

---

# Mobile Experience

The mobile experience provides users with a simplified and responsive view of workflow progress and submission statuses.

The mobile interface focuses on:
- Simplified navigation
- Clear status visibility
- Responsive layouts
- Reduced complexity

---

# Key Features

- Submission status tracking
- Workflow visibility
- Status indicators
- Structured review process

---

# Accessibility Considerations

The workflow is designed to support users with different levels of digital literacy through:
- Clear status labels
- Readable layouts and typography
- Consistent navigation
- Reduced cognitive load
