# Venture Submission
## Venture Pipeline Management System (VPMS)

---

# Overview

The Venture Submission feature allows Impact Users to submit venture applications and supporting documents through the VPMS platform.

The feature provides a structured workflow for collecting application information, managing document uploads, and supporting the review process.

---

# Purpose

The Venture Submission feature is designed to:
- Collect venture application information
- Support document uploads
- Allow users to track submission progress
- Support administrative review workflows

---

# Sprint 2 Progress

Sprint 2 improvements included:
- Improved submission workflow visibility
- Enhanced form structure and navigation
- Better document upload handling
- Improved submission status tracking
- Responsive layout improvements
- Improved accessibility and readability

---

# Submission Process

1. User navigates to the submission page
2. Required venture information is entered
3. Supporting documents are uploaded
4. Application is submitted for review
5. Submission status becomes visible to the user

---

# Web Experience

The web platform provides a more detailed and interactive submission experience, including document management, workflow visibility, and administrative actions.

---

# Mobile Experience

The mobile experience supports venture submissions through a simplified and responsive interface designed for smaller screens and easier navigation.

The mobile interface focuses on:
- Responsive layouts
- Simplified navigation
- Reduced complexity
- Mobile-friendly workflows

---

# Key Features

- Structured submission forms
- Document upload functionality
- Submission status tracking
- Workflow visibility
- Validation for required fields

---

# Accessibility Considerations

The feature is designed to support users with different levels of digital literacy through:
- Clearly labelled form fields
- Simple navigation
- Readable layouts and typography
- Clear validation feedback
- Reduced cognitive load
