# User Stories – Venture Pipeline Management System

## 👤 Founder (Entrepreneur)

### User Story 1
- **Description:** As a Founder, I want to write down my idea in the pipeline so that I can track its journey from start to finish.
- **Acceptance Criteria:**
  - Create a new entry with name, description, and stage
  - Idea appears in pipeline list after saving

### User Story 2
- **Description:** As a Founder, I want to collect and attach market research so that I can validate my idea.
- **Acceptance Criteria:**
  - Upload surveys, reports, or interviews
  - Idea must be marked as “validated” before progressing

---

## 👤 Admin (System Administrator)

### User Story 1
- **Description:** As an Admin, I want to manage user access and permissions so that only authorized users can use the system.
- **Acceptance Criteria:**
  - Create, modify, deactivate user accounts
  - Assign roles and permissions
  - Monitor login activity

---

## 👤 Impact User (Investor)

### User Story 1
- **Description:** As an Impact User, I want to view progress updates so that I can decide whether to invest.
- **Acceptance Criteria:**
  - View milestones, key results, financial needs
  - Download venture summaries

### User Story 2
- **Description:** As an Impact User, I want to compare ventures so that I can identify the most promising one.
- **Acceptance Criteria:**
  - Sort ventures by progress, results, funding needs
  - Compare multiple ventures side-by-side
---

## 👤 Project Manager

### User Story
- **Description:** As a Project Manager, I want to divide the pipeline into stages so that I can track progress effectively.
- **Acceptance Criteria:**
  - Stages include idea, testing, development, launch, growth
  - Ability to assign tasks to team members

---

## 👤 Mentor

### User Story 1
- **Description:** As a Mentor, I want to review ventures at each stage so that I can provide guidance.
- **Acceptance Criteria:**
  - Add comments or upload feedback
  - Entrepreneurs receive notifications

### User Story 2
- **Description:** As a Mentor, I want to share resources so that entrepreneurs receive the right support.
- **Acceptance Criteria:**
  - Upload guides, templates, links
  - Users can save/download resources

---

## 👤 Team Member

### User Story
- **Description:** As a Team Member, I want to see the current stage and assigned tasks so that I know what to focus on.
- **Acceptance Criteria:**
  - Dashboard shows stage and tasks
  - View assigned responsibilities

---

## 👤 Pipeline Manager

### User Story
- **Description:** As a Pipeline Manager, I want to set checkpoints so that ventures only progress when ready.
- **Acceptance Criteria:**
  - Checklist at each stage
  - Approval required before moving forward

---

## 👤 IT Support Specialist

### User Story
- **Description:** As an IT Support Specialist, I want to monitor system performance and resolve issues so that users can work without interruption.
- **Acceptance Criteria:**
  - Receive and respond to issues
  - Troubleshoot errors
  - Perform maintenance and track recurring issues
