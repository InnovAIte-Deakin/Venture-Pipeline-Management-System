# Accessibility
## Venture Pipeline Management System (VPMS)

---

# Overview

VPMS is designed to support users with different levels of digital literacy and technical experience.

The platform should be simple, clear, and easy to use for:
- Impact Users
- Administrators
- Team members

Accessibility is important because it helps users:
- Navigate the system easily
- Understand information clearly
- Complete tasks without confusion
- Use the platform regardless of technical ability

---

# Current Accessibility Considerations

## Simple Navigation
- Clear page structure
- Consistent navigation
- Easy-to-follow workflows

## Clear Labels
- Descriptive buttons and form fields
- Simple terminology
- Clear status indicators

## Readable Design
- Readable typography
- Clear spacing and layout
- Consistent visual hierarchy

## Reduced Cognitive Load
- Minimal unnecessary information
- Simplified workflows
- Organised content presentation

---

# Accessibility in VPMS

Impact Users need to:
- Submit venture applications
- Upload documents
- Track application progress
- Navigate workflows

Administrators need to:
- Review applications
- Manage workflows
- Update statuses
- Access administrative features

If the system is difficult to use, users may:
- Become confused
- Make workflow mistakes
- Miss important information

The platform should therefore remain intuitive and user-friendly for all users.

---

# Future Improvements

Future accessibility improvements may include:
- Screen reader support
- VoiceOver compatibility
- Improved keyboard navigation (eg. AI Copilot)
- Better WCAG compliance
- Enhanced responsive accessibility
