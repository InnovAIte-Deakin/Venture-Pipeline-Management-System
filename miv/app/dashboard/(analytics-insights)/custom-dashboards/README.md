# T5 Custom Dashboards

## Overview

The Custom Dashboards feature provides a dashboard-management interface within the VPMS frontend.

Users can currently:

- View existing dashboards.
- Search dashboards by name or description.
- Filter dashboards by category and visibility/favourite status.
- View dashboard summary statistics.
- Create dashboards.
- Edit existing dashboard details.
- Delete dashboards.
- Mark dashboards as favourites.
- Duplicate dashboards.
- Create dashboards from available templates.
- Access dashboard sharing controls.
- Open the Manage Widgets interface.
- Browse the Widget Library.
- Use the dashboard interface across desktop and smaller screen sizes.
